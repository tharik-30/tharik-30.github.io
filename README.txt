MOHAMED THARIK HUSSAIN — PORTFOLIO WEBSITE

RUN ON YOUR COMPUTER
1. Extract this ZIP.
2. Open VS Code > File > Open Folder > select MTH_Portfolio.
3. Open index.html.
4. Double-click index.html in File Explorer to preview in a browser.
   Optional: install the VS Code Live Server extension, right-click index.html,
   and choose Open with Live Server.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in to https://github.com/ using tharik-30.
2. Create a NEW PUBLIC repository named exactly: tharik-30.github.io
3. Upload the CONTENTS of this folder to the repository root:
   index.html, style.css, script.js, README.txt and assets folder.
   Do not upload only the ZIP file.
4. Open repository Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for publishing. Your site URL will be:
   https://tharik-30.github.io/

- Add a real profile photograph later if desired; MTH initials are used now.

  when you have them.
